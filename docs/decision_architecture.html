STAGE 3 · DECISION LAYER — THE CORE
Expected-loss engine routes every order
EVERY INTERVENTION IS PRICED, PER ORDER
EL(action) = friction_cost + P_rto_after × ₹150 − P_success × margin
margin = order_value × 20%  ·  ₹150 = forward + reverse logistics (industry prior)
route to → argmin EL over { ALLOW · VERIFY · DEPOSIT }
